## Why this matters

`Go To Special` is the most powerful cleaning tool in Excel and almost nobody uses it. It selects cells by *type* — every blank, every formula, every error — so you can act on all of them at once. Combined with one keyboard trick, it fixes a sparse column in about four seconds.

## How it works

### Find & Replace — <Kbd>Ctrl</Kbd>+<Kbd>H</Kbd>

Beyond the obvious, three things worth knowing:

**Options → Within: Workbook** replaces across every sheet at once. Useful, and worth being careful with.

**Wildcards.** `?` is any single character, `*` is any number of characters.

<FormulaBlock>
```
Find: Sales*        matches Sales, Sales Ops, Salesperson
Find: E1??1         matches E1001, E1231, E1991
Find: ~*            matches a literal asterisk (the ~ escapes it)
```
</FormulaBlock>

**Match entire cell contents.** Without it, replacing `HR` with `Human Resources` also mangles `CHRIS` into `CHuman ResourcesIS`. Tick it whenever you're replacing a short string.

<Shot id="7.3.1" />

<Callout type="warning">
Replace All across a workbook is not undoable sheet by sheet — one <Kbd>Ctrl</Kbd>+<Kbd>Z</Kbd> reverses the lot, but only if you notice immediately. Before any workbook-wide replace, click **Find All** first and read how many cells will change. If the count surprises you, your search string is wrong.
</Callout>

### Go To Special — <Kbd>F5</Kbd> then <Kbd>Alt</Kbd>+<Kbd>S</Kbd>

Select cells by what they are:

| Option | Selects | Use |
|---|---|---|
| **Blanks** | Every empty cell in the selection | Filling gaps, deleting empty rows |
| **Formulas → Errors** | Every error cell | Auditing before you suppress anything |
| **Constants** | Typed values, not formulas | Finding where someone overwrote a formula |
| **Formulas** | Every formula cell | Protecting or colouring them |
| **Visible cells only** | Ignores filtered-out rows | Copying filtered data safely |
| **Row differences** | Cells that break a pattern | Finding the one inconsistent formula |

<Shot id="7.3.2" />

### The fill-blanks technique

This is the one to memorise. A column where a value appears once and the rows beneath it are blank — the shape you get after unmerging cells, or from a grouped system export:

<FormulaBlock>
```
1. Select the column
2. F5 → Special → Blanks → OK        every blank is now selected
3. Type  =  then press  ↑            references the cell above
4. Press Ctrl+Enter                  applies to EVERY selected blank at once
5. Copy → Paste Values               makes it permanent
```
</FormulaBlock>

Four keystrokes fix a column of any length. The `Ctrl+Enter` is what does the work — it applies your relative reference to every selected cell simultaneously, so each blank picks up the value above it and the value cascades down.

<Callout type="tip">
`F5` → Special → **Constants** is how you audit an inherited workbook. In a column that should be entirely formulas, the constants are the cells where someone typed a number over your formula to "fix" a figure. That's the commonest way a working model quietly becomes wrong.
</Callout>

## Do it

| | A | B | C |
|---|---|---|---|
| **1** | Department | Employee | CTC |
| **2** | Sales | Anil Kumar | 640000 |
| **3** | | Meera Nair | 520000 |
| **4** | | Rahul Shah | 810000 |
| **5** | Finance | Sneha Rao | 470000 |
| **6** | | Kabir Menon | 920000 |

### Fill the blanks

1. Select **A2:A6**.
2. Press <Kbd>F5</Kbd> → **Special** → **Blanks** → OK. Three cells selected.
3. Type `=` then press <Kbd>↑</Kbd>. The formula bar shows `=A2`.
4. Press <Kbd>Ctrl</Kbd>+<Kbd>Enter</Kbd>. Every blank fills with the department above it.
5. Select A2:A6 → <Kbd>Ctrl</Kbd>+<Kbd>C</Kbd> → <Kbd>Ctrl</Kbd>+<Kbd>Alt</Kbd>+<Kbd>V</Kbd> → **Values** → OK.

<Shot id="7.3.3" />

That column is now usable in a pivot table. Before, three of five rows would have shown `(blank)`.

### Find the errors

6. Put `=C2/0` somewhere to create a `#DIV/0!`, and add one or two more.
7. <Kbd>F5</Kbd> → Special → **Formulas** → untick everything except **Errors** → OK.
8. Every error cell is selected at once. Read the count in the status bar.

### Find overwritten formulas

9. In D2 put `=C2*0.12` and fill down to D6.
10. Now type `50000` directly over D4 — simulating someone "correcting" a figure.
11. Select D2:D6 → <Kbd>F5</Kbd> → Special → **Constants** → OK. **D4 alone is selected.**

### Replace with Match entire cell

12. <Kbd>Ctrl</Kbd>+<Kbd>H</Kbd>. Find `HR`, Replace with `Human Resources`. Click **Find All** first — note the count.
13. Tick **Match entire cell contents**, then Find All again. The count drops to only the genuine department cells.

## Shortcuts

<ShortcutTable>

| Shortcut | What it does | When to use it | Example |
|---|---|---|---|
| `F5` then `Alt` + `S` | Opens Go To Special | Selecting every blank, error, formula or constant in one action | Blanks → fill down a sparse column |
| `Ctrl` + `Enter` | Applies your entry to every selected cell at once | The second half of the fill-blanks technique — this is what does the work | After selecting blanks, type `=`, `↑`, Ctrl+Enter |
| `Ctrl` + `H` | Find & Replace | Any bulk text change — click **Find All** before Replace All | Replacing a department name workbook-wide |
| `Alt` + `;` | Selects visible cells only | Copying filtered rows without the hidden ones | Filter, select, Alt+; , Ctrl+C |

</ShortcutTable>

## Watch out

<MistakeTable>

| Mistake | What you see | Fix |
|---|---|---|
| **Replace All without Match entire cell** | `CHRIS` becomes `CHuman ResourcesIS` | Tick Match entire cell contents for short strings |
| Replace All across a workbook unchecked | Changes on sheets you weren't looking at | **Find All** first and read the count |
| Skipping the Paste Values step | The column holds formulas referencing cells above — fragile, breaks on sort | Copy → Paste Values immediately after filling |
| Pressing Enter instead of `Ctrl`+`Enter` | Only the first blank fills | `Ctrl`+`Enter` applies to every selected cell |
| Deleting blank rows while filtered | Can silently remove hidden rows | Unfilter first, or copy visible rows to a new sheet |
| Assuming a blank-looking cell is empty | `""` from a formula isn't blank — Go To Special skips it | Check with `ISBLANK` (Lesson 3.2) |

</MistakeTable>

<Callout type="story">
**Kavya, Recruitment Coordinator.** Her candidate tracker used merged cells to group candidates by role — `Java Developer` merged across rows 4 to 7, `QA Engineer` across 8 to 11. It looked organised.

Her manager asked for candidates by role and by source. The pivot table returned `Java Developer` once and then `(blank)` three times, because merging keeps the value only in the top-left cell and genuinely empties the rest.

The repair took under a minute: unmerge the column, <Kbd>F5</Kbd> → Blanks, `=`, `↑`, <Kbd>Ctrl</Kbd>+<Kbd>Enter</Kbd>, then Paste Values. Every row carried its own role and the pivot worked immediately.

**Formatting that makes data look organised often makes it unanalysable.** Keep the data flat and use conditional formatting for the visual grouping instead.
</Callout>

<Scenario>
An export arrived with grouped headings, a formula someone overwrote, and a department name that changed.
</Scenario>

| **6** | | Kabir Menon | 920000 | `=C6*0.12` |

D4 is a typed number, not a formula.

</Dataset>

<Task>

1. Fill the blanks in column A using Go To Special, then make it permanent with Paste Values.
2. Find the cell in D where someone typed over the formula, using Go To Special → Constants.
3. Restore D4 to a formula.
4. Use Find & Replace to change `HR` to `Human Resources`. Click **Find All** first and note the count, then tick Match entire cell contents and compare.
5. Build a pivot-ready check: how many rows in column A were blank before step 1, and what would a pivot table have shown for them?
6. Add a `#DIV/0!` somewhere, then use Go To Special → Formulas → Errors to select every error on the sheet.

</Task>

<Expected>
Step 1: 3 blanks filled (A3, A4, A6) · Step 2: D4 selected alone · Step 4: without Match entire cell, `HR` also matches inside other text; with it, only the department cell · Step 5: a pivot would have shown `(blank)` for those 3 rows
</Expected>

<Solution>

```
Step 1: select A2:A7 → F5 → Special → Blanks → OK
        type  =  then ↑  then Ctrl+Enter
        select A2:A7 → Ctrl+C → Ctrl+Alt+V → Values → OK

Step 2: select D2:D7 → F5 → Special → Constants → OK
Step 3: D4: =C4*0.12
Step 4: Ctrl+H → Find HR → Find All (read count) → tick Match entire cell contents → Replace All
```

</Solution>

<Why>

**Step 1's Paste Values is not optional.** After the fill, A3 contains `=A2` rather than the text `Sales`. That works until someone sorts the data — then each formula follows its new position and points at whatever now sits above it, scrambling the column. Converting to values immediately makes the fix permanent and sort-safe.

**Step 2 is the audit habit worth keeping.** `Go To Special → Constants` on a column that should be all formulas finds every cell someone typed over. That's the commonest way a working model silently becomes wrong — a colleague "corrects" one figure, the formula is gone, and it never updates again. In a real payroll register, D4 would keep paying 97,200 regardless of what C4 becomes.

</Why>

</Exercise>
