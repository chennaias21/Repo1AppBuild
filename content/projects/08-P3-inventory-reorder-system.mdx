## The brief

You run operations for a company with 180 SKUs across two warehouses. Stock is currently tracked in a spreadsheet that shows only current quantity — it has no view of what's running low, what's overstocked, or what's been sitting unsold for months.

Last quarter you had two stockouts on fast-moving items and simultaneously wrote off ₹4 lakh of obsolete stock. Both were visible in the data; nobody was looking.

Your operations head wants a workbook that tells her what to order and what to clear, without her having to interpret anything.

## What you'll build

<Deliverable>

- [ ] A stock master as a Table with days-of-cover and stock value calculated
- [ ] A reorder status derived from a band table, not a nested IF
- [ ] Stock ageing buckets showing how long each SKU has been unsold
- [ ] A reorder list that populates itself — only items needing action
- [ ] Visual alerts: critical, low, healthy, overstocked, obsolete
- [ ] A Power Query import so the weekly warehouse export needs one click
- [ ] A summary showing value at risk, value obsolete, and SKUs to reorder
- [ ] All thresholds in labelled cells, so the ops head can change policy herself

</Deliverable>

## The data

**`RawStock`** — 180 SKUs: `SKU`, `Item`, `Category`, `Warehouse`, `OpeningQty`, `Received`, `Issued`, `ReorderLevel`, `UnitCost`, `Supplier`, `LeadTimeDays`, `LastIssueDate`

**`RawUsage`** — 12 months of monthly issue quantities per SKU, with **months across the columns** rather than down rows.

<Callout type="warning">
`RawUsage` is in the wrong shape for analysis — twelve month columns instead of one Month column. You'll need Power Query's **Unpivot** to turn it tall (Lesson 8.7). Doing it by hand takes an hour; unpivot is two clicks and re-runs next month.
</Callout>

There is no `ClosingQty` column. Derive it. Expect text-numbers in `UnitCost`, inconsistent `Category` spellings, and a few SKUs with a `LastIssueDate` over two years old.

|---|---|
| 0 | Critical |
| 7 | Low |
| 21 | Healthy |

<Milestone n="3" title="Flag it visually">

Conditional formatting on whole rows: red for Critical, amber for Low, grey for Overstocked, and a distinct flag for anything unsold for over 365 days.

<Milestone n="4" title="Build the self-populating reorder list">

On a `Reorder` sheet, produce a list containing **only** SKUs with status Critical or Low — item, supplier, quantity to order, lead time, and the date to order by.

Quantity to order should bring stock up to a target cover level held on `Rates`, rounded up to the supplier's pack size. Order-by date works backwards from lead time using working days.

Use a dynamic array so the list resizes itself. If you're on an older Excel version, use a helper column and a filter instead.

## Solution walkthrough

<Walkthrough>

**Table columns in `Stock`:**

<FormulaBlock>
```
ClosingQty    =[@OpeningQty]+[@Received]-[@Issued]
StockValue    =[@ClosingQty]*[@UnitCost]
AvgMonthly    =IFERROR(AVERAGEIFS(Usage[Qty],Usage[SKU],[@SKU]),0)
DaysCover     =IFERROR([@ClosingQty]/([@AvgMonthly]/30),999)
DaysSinceIssue =IF([@LastIssueDate]="",999,TODAY()-[@LastIssueDate])
Status        =IFERROR(VLOOKUP([@DaysCover],Rates!$A$2:$B$5,2,1),"Unclassified")
AgeBucket     =IFERROR(VLOOKUP([@DaysSinceIssue],Rates!$D$2:$E$5,2,1),"Unknown")
```
</FormulaBlock>

Note `DaysCover` returns `999` rather than an error when average usage is zero — a SKU with no usage has effectively infinite cover, and 999 keeps it sortable and lands it in the Overstocked band correctly. Returning `""` would break the lookup that follows.

**The reorder list** — dynamic array version:

<FormulaBlock>
```
=LET(rows, FILTER(Stock,(Stock[Status]="Critical")+(Stock[Status]="Low"),"Nothing to order"),
     SORT(rows, 5, 1))
```
</FormulaBlock>

**Quantity to order,** brought up to target cover and rounded up to pack size:

<FormulaBlock>
```
=CEILING(MAX(0,([@AvgMonthly]/30*Rates!$B$8)-[@ClosingQty]),[@PackSize])
```
</FormulaBlock>

The `MAX(0,...)` prevents a negative order quantity, and `CEILING` rounds up to a whole pack — you cannot order two-thirds of a carton (Lesson 3.4).

**Order-by date,** working backwards from lead time:

<FormulaBlock>
```
=WORKDAY(TODAY()+[@DaysCover]-[@LeadTimeDays],0,Holidays)
```
</FormulaBlock>

**Conditional formatting,** most serious rule first with Stop If True:

<FormulaBlock>
```
=$K2="Critical"                  red fill        Stop If True
=$K2="Low"                       amber fill      Stop If True
=$L2="Obsolete (365+ days)"      purple border
=$K2="Overstocked"               grey fill
```
</FormulaBlock>

</Walkthrough>

## How this is marked
