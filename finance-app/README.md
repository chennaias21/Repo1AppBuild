# Rupee Routine – Money Made Simple

Personal finance app for **web and Android** from one codebase. Offline-first, no accounts, no cloud: your data stays on your device.

* **Guide (run, build APK, backup/restore):** [GUIDE.md](./GUIDE.md)
* Stack: React + TypeScript + Vite, Dexie (IndexedDB), Capacitor 6 (Android), Zod, Vitest, Playwright
* Quick start: `npm install && npm run dev`
* Tests: `npm test` (unit) · `npm run build && node tests/e2e/smoke.mjs` (browser end-to-end)
